# paps

Paps is a 3D game made with [Godot 4](https://godotengine.org/).

## Controls

| Action | Key |
|--------|-----|
| Move | WASD |
| Jump | Space |
| Sprint | Shift |
| Interact | E |
| Inventory | I |
| Fire Weapon | F |
| Reload Weapon | R |
| Pause | Escape |
