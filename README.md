# paps

A small 3D game made in [Godot 4](https://godotengine.org/).

## Controls

| Action | Key |
|--------|-----|
| Move | WASD |
| Jump | Space |
| Sprint | Shift |
| Pause | Escape |

## Running

Open `project.godot` in Godot 4 and press **Run**.
